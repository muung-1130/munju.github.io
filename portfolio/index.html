7개 프로젝트의 개인 담당·공동 참여 기록을 기준으로 정리했습니다. 카드형에서는 활용 맥락을, 목록형에서는 기술 이름을 간결하게 볼 수 있습니다.

프로젝트별 담당 범위 · 팀 기술 · 후속 과제

DAI RUN: CI/CD·GitOps·VPN과 FastAPI 기반 AI 러닝 챗봇의 RAG·사용자 문맥·DB 조회·가드레일 구축. 서비스 전체 프론트엔드와 MSA 개발은 팀 산출물입니다.

NFS: NFS 공유, 서버·클라이언트 연결, 계정·권한과 파일 이벤트 수집. iSCSI·RAID·SMB·백업 서버는 팀 연계 구성입니다.

CampUs · Paw-Data: CampUs의 주제·요구사항·모델링·파티셔닝 검증과 공동 데이터 구축, Paw-Data의 자료 조사·정규화·DB 구축 참여 및 React·API 연결. Python·pandas는 데이터 처리 협업 범위를 포함합니다. Paw-Data 백엔드 전체 개발은 개인 담당으로 표시하지 않았습니다.

낭만노숙: GitHub Actions·러너·Harbor·SonarQube 연계, DB 백업·알림, 내부망과 부하 점검. 두 러너를 통한 병렬 빌드 경험은 이 프로젝트에 해당합니다.

Newdrops: Kubernetes 인프라, Jenkins CI/CD, Windows·WSL 2 기반 Harbor 설치와 Argo CD·MinIO 연계. 제출 Jenkinsfile은 순차 빌드이며 SonarQube·Trivy는 비차단 검사입니다.

etcd 개인 실습: 스냅샷 백업·복원, 장애 상태와 노드·etcd 실행 상태 확인.

팀 기술로 구분: Kafka Saga, Istio·Calico·MetalLB, HPA·KEDA 및 Prometheus·Grafana·Loki·Tempo·Alloy 전체 구축은 팀 구성으로 소개하며 개인 주도 구축 목록과 구분합니다.

후속 과제로 구분: Newdrops의 JCasC 적용·변경 감지 병렬화·강제 품질 게이트, DAI RUN의 서비스별 병렬 matrix 빌드는 완료 기술로 포함하지 않았습니다. 각 프로젝트의 검사·검증 범위는 상세 페이지에서 확인할 수 있습니다.
